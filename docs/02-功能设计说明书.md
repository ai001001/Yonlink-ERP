# 陶瓷工艺品工贸一体外贸 ERP —— 功能设计说明书

## 1. 技术架构

| 层次（对标亿星四层） | 实现 |
|---|---|
| 公共数据底座 | SQLite（Node.js 内置 `node:sqlite`，单文件 `data/erp.db`），35 张业务表；可平滑迁移 MySQL |
| 松耦合业务模块层 | `server/routes/*.js`，16 个模块，每个模块独立权限键，可一键启停 |
| 智能联动风控层 | 订单变更风险评估、联动任务派发与锁定、旧货号锁定、验货/质检/审批闸口 |
| 前端可视化层 | 原生 JS 单页应用（`public/`），岗位化菜单，手机自适应，深色模式 |

- **零第三方依赖**：只需安装 Node.js ≥ 22.5，无需 `npm install`，Excel 导出为自研 xlsx 生成器。
- 启动：`node server/index.js`（默认端口 8080），浏览器访问即可，多人可同时在线。
- 安全：scrypt 密码哈希、令牌会话（12 小时）、全部 SQL 参数化、所有接口后端权限校验（前端隐藏按钮仅为体验）。

## 3. 核心业务规则

### 3.1 报价与工厂询价
1. 选择样品后自动带出描述、生产厂家、成本（材料+人工）、MOQ。
2. 单价公式：`(成本 + 工艺加价 + (物流费+报关费)/总数量) × (1+利润率%) ÷ 汇率`，保留 2 位；可取消自动计算手动微调。
3. 报价单号 `QT+日期-流水`；状态：草稿 → 待审批 → 已审批/已驳回 → 已发客户 → 已成交/已失效。已审批后再修改自动退回草稿并撤回审批。
4. 提交审批时若利润率低于系统参数「最低利润率」（默认 15%），审批标题标注 ⚠ 预警。
5. **一键拆分询价单**：按每行「生产厂家」分组，生成 `报价单号-厂家名称` 的询价单；重复拆分不重复生成，已回价的不覆盖。
6. **追加厂家询价**：同一货号可再向其它厂家询价，形成多厂家比价。
7. **导出 Excel**：厘米版/英寸版两套模板（英寸 = 厘米 ÷ 2.54），自动填充货号、工厂货号、描述、尺寸、材质工艺、包装、标签、内盒、外箱、装箱数、CBM、MOQ、数量，底部左「本次新创货号」右「详细改样要求」。
8. **回填**：录入工厂单价、交期、备注、回价日期、有效期 → 状态「已回价」，同时写入供应商历史价格台账。
9. **对比**：按货号列出所有厂家回价，按价格升序，显示与最低价差、与当前成本差、交期、评级/合格率、按此价预估毛利；「采用」后回写成本与厂家并重算单价。
10. **改新货号**：每行可录入新货号+改样要求，系统写入原样品改样日志（旧-新货号关联）；新货号不得与原货号相同、不得占用他人货号。

### 3.2 送样与改样新货号闭环
1. 送样单号 `SS+日期-流水`；状态：申请中 → 已寄出（必填快递公司/单号，自动扣减样品库存）→ 客户确认/客户拒绝。
2. 带新货号的明细初始为「待核验」；跟单核验不通过必须填整改意见，重做次数+1、样品进度置「重做中」，全部留痕。
3. 核验通过后「一键转正」：新建正式样品档案（新货号为公司货号、`原货号`字段记录旧货号），**继承原设计师、改样记录、工艺参数**，可覆盖工艺/花色/图片。
4. 转正同时**锁定旧货号**：旧货号不可再用于报价、下单、出货（后端强校验），下拉框不再出现；含旧货号的已审批报价也不能转订单，须改为新货号重新审批。

### 3.3 订单变更强制风控（方案核心）
- **风险评估**：
  - 高：关联采购单已入库 或 已付款（审批通过）或 关联布产已报工；
  - 中：已下采购单/已布产但未入库、未付款、未报工；
  - 无：其它。
- **关键参数**：交期、包装要求、工艺要求、各行数量/工艺/规格/包装、增删产品、换货号（单价变化仅通知财务）。
- **流程**：关键参数变更且风险≥中 → 后端返回 409 风险详情 → 前端弹窗展示风险依据、变更对比、受影响采购/布产 → 必须填写变更原因方可确认。
- **确认后**：生成变更单 `CH+日期-流水`；自动派发联动任务（有采购→采购；有布产→生产；财务、业务必派）；订单进入**风控锁定**：禁止再次修改订单、新增关联采购、新增布产、安排出货、报关/出运。
- **解锁**：各任务只能由对应部门权限的人处理（必须填写处理说明）；全部处理完毕自动解锁。全程留痕。
- 数量不得小于已出货数量；已有出货/布产的明细不可删除。

### 3.4 出货与验货闭环
- 出货数量不能超过「订单数 − 已安排出货」；箱数默认按装箱数向上取整，CBM 按外箱尺寸自动计算。
- 验货：待验货/合格/不合格（不合格必填问题与整改）；**验货合格后才能报关/出运**；出运必填报关单号。
- 出运后自动更新订单为「部分出货/已出货」；已出运单据不可修改。

### 3.5 应收与开票
- 收款类型：预收/尾款/分期；不得超过未收余额；按收款汇率折人民币，**汇兑损益 = 金额 × (收款汇率 − 订单汇率)**。
- 销项发票：发票号全局唯一（防重开），累计不得超过订单金额（防超开）；作废需删除权限。
- **开票逾期预警**：首次出运日起超过「开票期限(天)」仍有未开票余额 → 工作台红色预警。
- 订单收齐货款后才能完结。

### 3.6 采购、库存、生产
- 采购单 `PO`；外购成品须**质检合格**才能入库；入库更新库存（加权平均成本）并写历史价格；不可超量入库。
- 付款申请 → 财务审批（审批中心）→ 计入已付；申请总额不得超过采购金额。
- 进项发票防重复、防超开；财务核销。应付台账按供应商汇总应付/已付/未付/已收票/已核销。
- 库存低于安全库存 → 缺料预警；高于最高库存 → 积压预警。
- 一键布产 `MO`：按订单未布产数量生成；工序顺序校验：后道工序累计良品 ≤ 上道良品，制坯 ≤ 计划数；包装良品达到计划 → 已完工；订单全部完工 → 订单「待出货」。
- 领料：按订单/布产单领料，库存不足拦截，成本自动归集订单 → 订单成本核算（收入、采购成本、领料成本、汇兑损益、毛利）。

### 3.7 设计师数据隔离与提成溯源
- 设计师角色数据范围 = 「设计师本人样品」：样品列表/详情、报价/送样/订单列表只出现含本人样品的单据，详情只显示本人样品行；看不到变更、采购、成本等敏感信息；无任何新增/修改/删除权限。
- 速查中心：设计样品数、被报价次数、送样次数、下单数量/金额、已出货数量、未出货数量、**提成核算基数 = 已出运金额（折人民币）**；五大明细查询（样品档案/报价/送样/订单/出货）可按货号、日期、状态筛选，可导出与打印对账单。
- 设计师传入他人 `designer_id` 参数会被忽略；管理员可选择任意设计师查看。

## 5. V2 新增：企业邮箱、汇率自动更新、样品图片上传

### 5.1 企业邮箱直连（菜单：业务邮件 / 邮箱账户）
- **账户**：每位员工绑定自己的邮箱（SMTP 发信 + IMAP 收信，支持 SSL / STARTTLS / 不加密，可关闭证书校验以兼容自建服务器）；密码/授权码以 **AES-256-GCM 加密**保存，密钥位于 `data/secret.key`（或环境变量 `ERP_SECRET_KEY`），接口永不回传密码。
- **自动识别**：输入邮箱后按域名 MX 记录识别腾讯企业邮、阿里企业邮、网易企业邮、QQ、163、Gmail、Microsoft 365、Zoho 并自动填入服务器参数；识别到 **Cloudflare 邮件路由**（如 316191099.xyz）时给出配置指引。
- **发信**：写邮件/回复/再次发送，中文主题与显示名按 RFC 2047 编码；失败的邮件保留为「发送失败」并显示原因，可修正账户后一键重发。
- **收信**：手动「收取邮件」或定时自动收取（默认每 10 分钟）；按 UID 增量收取，Message-ID 去重；首次只同步最近 50 封；支持 GBK/GB2312/UTF-8、Base64/Quoted-Printable、多段 MIME、RFC 2231 中文附件名，附件保存（单个≤15MB）可下载。
- **自动绑定**：按往来邮箱匹配客户；按主题/正文中的报价单号 `QT…`、订单号 `SO…`、样品货号匹配报价、订单、样品；按关键词自动分类（询盘/报价/样品/订单/出货/售后）。绑定可在详情中人工调整。
- **询价单直发厂家**：询价单页「邮件发送给厂家」，自动附带厘米版/英寸版 Excel，发送成功自动标记「已发送」。供应商档案新增「邮箱」字段。
- **数据范围**：业务员看到 本人邮箱的邮件 + 本人负责客户的往来邮件；管理员看全部。员工离职后邮件仍留存在系统中。
- **演示版**：浏览器无法直连邮件服务器，邮箱账户功能在 GitHub Pages 演示版中提示需使用服务器版；「登记线下邮件」仍可用。

### 5.2 汇率自动更新（菜单：币种汇率）
- 「⟳ 自动更新汇率」按钮 + 定时更新（默认每 24 小时）；主接口 open.er-api.com，失败自动切换 frankfurter.app（欧洲央行数据）；接口地址可在系统参数中修改。
- 兼容任意基准货币：`1外币折人民币 = rates.CNY ÷ rates.外币`；日元等小额币种保留 6 位小数。
- **异常保护**：单次变化超过阈值（默认 30%）的币种不自动采用，结果中标明原因。
- 每次变化写入「汇率波动记录」（操作人显示为具体用户或「汇率自动更新」）与系统日志；新报价/订单/收款自动取最新汇率，已有单据保留各自汇率。

### 5.3 样品图片上传（菜单：样品档案 → 样品详情）
- 多图上传，浏览器端自动压缩（最长边 1600px、JPEG 质量 0.85，例：4.4MB → 283KB）；服务器按文件头校验格式（JPG/PNG/GIF/WEBP），单张≤5MB。
- 相册展示、点击放大、删除；图片存数据库，需登录才能访问，设计师仅能查看本人样品图片；上传记录写入改样日志。原有「图片链接」方式继续兼容。

## 6. 当前限制
- 正式收发邮件需要您提供真实邮箱的服务器参数与密码/授权码（在「邮箱账户」中由本人填写）。注意 316191099.xyz 使用 Cloudflare 邮件路由，本身没有收件箱和发信服务：收信请连接“转发目标邮箱”，发信需支持以该地址发信的 SMTP 服务。
- 数据库为 SQLite 单文件，适合中小企业；用户量大时可迁移 MySQL。
