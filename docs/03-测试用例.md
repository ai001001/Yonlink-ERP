## 十一、给您的手工验收清单（建议按顺序操作，约 20 分钟）

1. **启动**：在项目目录运行 `node server/index.js --reset`，浏览器打开 http://localhost:8080
2. **业务员 sales1**：客户档案 → 点客户名称看全景页；新建报价（选 YL-V001，填「改新货号」与「详细改样要求」）→ 保存 → 一键拆分询价单 → 打开询价单导出厘米版/英寸版 Excel 查看模板 → 打印报价单看左下/右下布局 → 提交审批。
3. **采购 purchase1**：工厂询价台账 → 打开询价单回填工厂单价 → 回到报价单点「多厂家报价对比」。
4. **经理 manager1**：审批中心通过报价 → 报价单「转为订单」。
5. **采购 purchase1**：订单详情「新建采购」→ 入库 → 申请付款；**财务 finance1** 审批付款。
6. **业务员 sales1**：打开订单改数量 → 观察**风险弹窗** → 填原因确认 → 订单被锁定。
7. **采购/财务/业务**各自登录 → 工作台或「变更联动任务」处理 → 订单自动解锁。
8. **生产 prod1**：订单「一键布产」→ 布产进度依次报工五道工序。
9. **业务员**：订单「安排出货」→ 更新为验货合格 → 填报关单号 → 已出运。
10. **财务**：应收款与开票 → 登记收款（换个汇率看汇兑损益）→ 登记发票（试重复发票号）。
11. **送样**：sales1 新建送样单（填新货号）→ 登记寄出 → 核验不通过/通过 → 用 manager1「一键转正归档」→ 再用旧货号报价，确认被拦截。
12. **设计师 designer1**：只看到本人样品；速查中心看提成基数 → 打印对账单。
13. **admin**：系统权限管理 → 停用某模块看菜单变化；配置角色权限矩阵；统计报表 8 个口径。
14. 用手机浏览器访问（同一局域网填电脑 IP:8080）检查审批与查询。
