# 陶瓷工艺品工贸一体外贸 ERP —— 原型设计

> 依据：《陶瓷工艺品工贸一体外贸ERP系统软件开发总体方案（对标亿星ERP、业务流程化、订单变更风控版）》
> 版本：V1.0　日期：2026-11-04　形态：B/S 浏览器端，电脑/手机自适应

## 1. 信息架构（菜单按真实业务流程排序）

```
工作台
 ├─ 工作台首页（待办与预警、业务流程导航）
 ├─ 审批中心（报价审批、付款审批；手机可审批）
 └─ 变更联动任务（订单变更后派发到采购/生产/财务/业务）
一期 · 基础档案
 ├─ 系统权限管理（模块启停 / 岗位角色权限矩阵 / 账号 / 系统参数 / 日志）
 ├─ 部门、员工档案
 ├─ 供应商、历史供货价格台账
 ├─ 服务机构、机构对接记录（设计机构/打样厂/货代/报关行/验货机构）
 └─ 客户档案（客户全景页）、客户跟进/询盘
二期 · 外贸开发
 ├─ 业务邮件（按邮箱自动绑定客户，可绑定样品/报价/订单）
 ├─ 样品档案（三货号、设计师、成本、包装、外箱；样品全景页）、改样日志
 ├─ 币种汇率、汇率波动记录、贸易术语
 ├─ 报价单（含【工厂询价子模块】：拆分询价单 / 回填 / 对比 / 导出）
 ├─ 工厂询价台账
 └─ 送样单（送样阶段改新货号 → 核验 → 转正归档 → 锁定旧货号）
三期 · 订单出货
 ├─ 销售订单（变更强制风控）
 └─ 出货台账（验货闭环、报关、海运）
四期 · 财务收付
 ├─ 应收款与开票（收款、汇兑损益、销项发票、开票逾期预警）
 ├─ 采购单（原辅材料/外购成品、质检、入库、付款申请、进项发票）
 ├─ 应付与进项票
 └─ 物料库存（缺料/积压预警）
五期 · 生产管控
 └─ 布产进度（一键布产、工序报工、领料按单核算）
六期 · 统计分析
 ├─ 统计报表（业务/样品/生产/供应链/财务/外贸/设计师/改样溯源 8 大口径）
 └─ 设计师速查中心（五大溯源查询 + 提成基数 + 对账单打印）
```

## 4. 交互规范
- 所有列表：关键字搜索、分页、导出 Excel（按权限）、打印（按权限）。
- 所有表单：必填项红色 *；错误以顶部红色提示条显示中文原因。
- 高风险操作（删除、变更、转正）均有二次确认弹窗。
- 手机端（≤860px）：侧边菜单收为 ☰ 抽屉、统计卡片两列、表格横向滑动、页面无横向溢出。
- 深色模式：跟随系统自动切换。
