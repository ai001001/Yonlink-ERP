# 陶瓷工艺品外贸 ERP —— 亿星兼容与数据迁移方案

> 编写日期：2026-11-06
> 依据：亿星软件官方教学知识库「亿星软件教学视频」（语雀，新版 V【5G】25.x～26.x），共 655 篇文档、394 个教学视频。其中文字文档 33 篇已全部通读；视频按模块抽取关键画面（字幕 + 界面字段）逐一核对。
> 原则：**本系统现有功能保持不变**；在此基础上兼容亿星的字段叫法与操作习惯，并提供从亿星迁移数据的通道，让使用亿星的客户能平稳切换。

## 一、调研概况

### 1.1 亿星知识库结构

### 1.2 亿星的核心操作习惯（客户员工已经熟悉的用法）

1. **左侧导航树 + 右侧列表**：每个列表左侧都有可自定义的多级导航树（如“业务员→客户”“国别→客户”“审核状态”“系列→功能→造型”），节点后显示数量，点节点即筛选。
2. **快速查找区**：列表左下角固定几个查询框（客户编号、简称、Email、业务员……），配“查找 / 过滤 / 检索”三个按钮。
3. **单据 = 表头 + 多页签明细**：例如订单有「货号明细、订单概要、唛头、合同条款、效益测算、加减项、货号图片明细、费用、相关文件、订单变更」页签；客户有「基本信息、联系人、业务信息、业务记录、提醒、洽谈、文件、唛头、货代、来访、展会、银行、标签」页签。
4. **审核 / 反审 / 结案 / 作废**：所有单据都有审核状态，审核后不能修改；订单还分别审核套件、配件、标签、工序、包材、图片、文件。
5. **Excel 导入（覆盖原有记录 = 以 Excel 为准）**，导入后弹出结果窗口，分为「新增到数据库的记录 / Excel 中重复的记录 / 数据库中已存在且覆盖的记录 / 厂家不存在未导入 / 无新增权限 / 货号已审核未导入」。
6. **另存为 / 历史翻单**：报价单另存为订单、送样单；订单另存为新订单；按历史记录快速翻单。
7. **单价锁定、利润率与单价互算**：每一行可锁定单价；改利润率自动算单价，改单价反算利润率。
8. **数据提取 / 同步回样品档案**：订单、出货可从样品档案提取资料，也可把修改同步回样品档案。
9. **业务记录查看**：客户、厂家、货号都能一键查看历史报价、送样、下单、出货、应收记录。
10. **业务交接**：人员离职时一键把客户、厂家、单据转交给其他员工。

### 1.4 已验证的亿星计价公式

在「报价单中利润率与单价互算」视频中用 3 行数据核对，结果完全一致：

```
单价(外币) = 报价基准(人民币) ÷ 换汇成本 × (1 + 利润率)
例：42.76 ÷ 6.00 × 1.20 = 8.552（视频显示 8.552）
报价基准 = 工厂报价 + 配件 + 包材 + 工价 + 其他 + 分摊的FOB费用
FOB费用分摊 = FOB总费用 ÷ 整柜体积 × 每箱CBM ÷ 每箱只数
```

本系统现有公式为 `单价 = 成本 × (1 + 利润率) ÷ 汇率`，**结构相同**。差异在于：亿星按行设利润率、按体积分摊费用、使用“换汇成本”而不是实时汇率、可锁定单价（列入后续批次）。

## 三、数据迁移方案

### 3.1 迁移路径

| 路径 | 做法 | 适用 | 状态 |
|---|---|---|---|
| **A. Excel 导入（推荐，已实现）** | 在亿星各列表用「单据输出 / Excel导出」导出 → 本系统【系统设置 → 数据迁移（亿星导入）】导入 | 基础资料（客户、厂家、样品），数据量几千～几万条 | ✅ 批次1 |
| B. 数据库直连抽取 | 由亿星实施工程师或客户 IT 提供数据库只读账号/备份，按表结构编写抽取脚本，转成路径 A 的表格格式 | 历史单据量大、需要整体迁移 | 待客户提供数据库类型与表结构 |
| C. 期初余额 | 切换日只导入“未完结”的订单、未收应收、未付应付作为期初 | 财务切换 | 批次5 |

> 路径 B 的前提是亿星数据库的访问权与表结构说明，属于亿星软件的数据，需要客户向亿星确认后提供；我们不会绕过亿星的授权去读取。

### 3.2 迁移顺序

1. 员工与账号（在本系统先建好，导入时按姓名或工号匹配业务员、跟单员、设计师）
2. **厂家档案**（样品引用厂家，必须先导）
3. **客户档案**
4. **样品档案（货号）**
5. 未完结订单 / 报价（批次2）
6. 应收、应付期初余额（批次5）

### 3.3 已实现的导入功能（批次1）

入口：【系统设置 → 数据迁移（亿星导入）】，需要“系统权限管理”的新增权限（回滚需要删除权限）。

| 能力 | 说明 |
|---|---|
| 文件格式 | .xlsx（Excel / WPS 均可）、.csv（UTF-8 或 GBK）；旧版 .xls 提示“另存为 .xlsx” |
| 自动找表头 | 亿星导出的表格第一行常是标题，系统在前 15 行中自动找表头，也可手动指定 |
| 按亿星列名识别 | 每个字段登记了亿星叫法和常见别名（如 客户简称/客户名称、厂号/工厂货号、外箱规格/外箱尺寸），识别不对可手动改选 |
| 智能转换 | “13.00 × 6.00 × 31.00”自动拆成长宽高；“5%”“1,200.50”转数字；“停用”列的 是/√/1 转为停用；采购类型“产品/包材”推导供应商类型 |
| 关联匹配 | 业务员、跟单员、设计师按员工姓名/工号/账号匹配；厂家按编号/简称/全称匹配；同一批次内的“合作厂家”也能互相关联 |
| 不丢信息 | 不在下拉选项中的原值（如客户等级“白金客户”）写入备注【亿星原值】 |
| 先校验后导入 | 「校验」完整走一遍但不写数据库；「正式导入」写入 |
| 结果分类（同亿星） | 新增 / 已存在且已覆盖 / 已存在未覆盖 / Excel 中重复 / 关联资料不存在 / 已锁定 / 数据不完整，逐行给出 Excel 行号和原因 |
| 覆盖规则 | “覆盖原有记录”只改 Excel 中有值的列，空单元格不会清空系统原有数据；被订单锁定的旧货号不允许覆盖 |
| 批次与回滚 | 每次导入生成批次号（IMP…），可查看明细；某类资料最近一次导入可整批回滚：新增的删除、覆盖的恢复原值；已被报价/订单/样品引用的记录保留不删 |
| 导入模板 | 可下载亿星列名的空白模板，必填列带 * |

### 3.4 需要注意的结构差异

| 差异 | 亿星 | 本系统 | 迁移处理 |
|---|---|---|---|
| 出货单 | 以发票号为单位，可合并多张订单、分柜 | 一张出货单对应一张订单 | 批次5 增加“发票/出货中心”合并多订单；迁移历史出货时按订单拆分 |
| 应收应付 | 由出货、送样、订单定金自动生成的台账 | 按订单登记收款 | 批次5 增加应收台账；期初按“未收余额”导入 |
| 利润率 | 每行一个利润率，可锁定单价 | 每张报价一个利润率 | 批次2 增加行级利润率与锁定，原整单利润率作为默认值 |
| 费用分摊 | 按 CBM 分摊 FOB 费用 | 按数量分摊 | 批次2 增加“按体积分摊”选项，默认保持现有方式 |
| 样品明细 | 配件、工序、包材明细，多包装方案 | 耗材、包装要求为文字 | 批次4 增加明细表，可从亿星“配件/工序/包材明细 Excel 导入” |
| 审核 | 所有单据审核后锁定 | 报价、订单、付款审批 | 保持现有审批流，不强制改变 |

### 3.5 切换建议

1. **试导**：先用亿星导出的真实表格在测试环境校验，修正姓名、厂家不一致等问题。
2. **并行期 1～2 周**：新业务在本系统录入，亿星只查不改。
3. **切换日**：导入最终版基础资料（覆盖方式）＋未完结订单＋期初应收应付。
4. **核对**：客户数、厂家数、货号数、未收/未付余额与亿星报表逐项核对。

## 四、分批开发计划

## 五、需要客户提供的信息

1. 亿星实际在用的模块清单（尤其是否在用生产、库存、财务模块）。
2. 各列表导出的样例表格（客户、厂家、样品各一份，可脱敏），用于确认列名与实际导出格式。
3. 亿星数据库类型、版本，以及是否能取得只读备份（决定是否走路径 B）。
4. 计划切换日期、并行期安排。
