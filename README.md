# 永联陶瓷工艺品工贸一体外贸 ERP

对标亿星 ERP 架构、按业务流程排布、含**订单变更强制风控**、**工厂询价子模块**、**改样新货号闭环**、**设计师提成溯源**的陶瓷工贸外贸 ERP。B/S 架构，电脑和手机浏览器均可使用。

## 在线演示

**https://ai001001.github.io/yonlink-ceramic-erp/**

演示版把同一套后台逻辑打包进浏览器运行（WebAssembly 版 SQLite），无需安装即可体验全部功能（浏览器无法直连邮件服务器，企业邮箱收发需使用服务器版）。注意：演示数据只保存在您当前的浏览器里，不同电脑/浏览器之间不共享，可在登录页点「重置演示数据」恢复初始数据。**正式多人使用请按下面的方式在服务器上运行。**

每次推送到 `main` 分支，GitHub Actions 会先运行 61 条自动化测试，通过后自动构建并发布演示版（见 `.github/workflows/pages.yml`）。本地构建：`node scripts/build-pages.js`（输出到 `dist/`）。

## 快速开始

只需安装 [Node.js](https://nodejs.org/) 22.5 或更高版本，**无需安装任何依赖包**。

```bash
node server/index.js
```

浏览器打开 http://localhost:8080 ，演示账号密码均为 `123456`：

| 账号 | 岗位 | 账号 | 岗位 |
|---|---|---|---|
| admin | 超级管理员 | designer1 | 陶瓷设计师（张雕塑） |
| sales1 | 外贸业务员（林晓明） | designer2 | 陶瓷设计师（李彩绘） |
| sales2 | 外贸业务员（王芳） | purchase1 | 采购 |
| manager1 | 业务经理（审批） | prod1 | 生产管理 |
| finance1 | 财务 | hr1 | 人事 |

常用命令：

```bash
node server/index.js --reset          # 重置为演示数据后启动
node server/index.js --port 9000      # 指定端口
node --test tests/*.test.js                    # 运行 61 条自动化测试（含模拟邮件服务器）
```

数据保存在 `data/erp.db`（单文件，复制即备份）。同一局域网的手机可通过 `http://电脑IP:8080` 访问。

## 企业邮箱、汇率、图片（V2）

- **企业邮箱**：「业务邮件 → 邮箱账户」添加自己的邮箱，点「按邮箱自动识别」自动填写服务器参数，填写密码/授权码后「测试连接」。之后即可在系统内写信、回复、收信（默认每 10 分钟自动收取），邮件自动绑定客户/报价/订单/样品；询价单可一键邮件发给厂家（自动附 Excel）。密码加密存于数据库，密钥在 `data/secret.key`（请与数据库一起备份）。
- **汇率**：币种汇率页「⟳ 自动更新汇率」，默认每 24 小时自动更新，波动异常自动拦截。
- **样品图片**：样品详情页「＋ 上传图片」，自动压缩。
- **邮件模拟测试**：`node tests/mock-mail-server.js` 启动本机模拟邮件服务器（ai001/ai002/ai003@316191099.xyz，密码见该文件），用于不连接真实邮箱的演练。
- 不需要定时任务时可用 `node server/index.js --no-scheduler` 启动。

## 目录结构

```
server/            后端（零依赖 Node.js）
  index.js         启动入口
  app.js           路由装配与错误处理
  db.js            建表与演示数据
  entities.js      档案类实体元数据（通用增删改查）
  xlsx.js          Excel 生成器
  routes/          base(权限/档案/审批) sales(报价/询价/送样) orders(订单/风控/出货)
                   finance(应收/采购/库存/生产) reports(报表/设计师)
public/            前端单页应用（原生 JS，手机自适应）
pages/            浏览器演示版运行时（Node 内置模块替代、请求拦截、IndexedDB 存储）与 sql.js
scripts/          build-pages.js 演示版构建脚本
tests/             自动化测试
docs/              原型、功能设计、测试用例、测试报告
```
