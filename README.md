## 快速开始

只需安装 [Node.js](https://nodejs.org/) 22.5 或更高版本，**无需安装任何依赖包**。

```bash
node server/index.js
```

浏览器打开 http://localhost:8080 ，登录页以表格列出 12 个演示账号及各自的复杂密码，点「填入」即可登录。

> **正式使用前务必**：在「系统权限管理 → 系统参数」中把「登录页显示演示账号」设为不显示，并为每个账号重置密码（系统会生成一次性临时密码，员工首次登录必须修改）。工作台的「安全提醒」会提示尚未处理的事项。


常用命令：

```bash
node server/index.js --reset          # 重置为演示数据后启动
node server/index.js --port 9000      # 指定端口
node --test tests/*.test.js                    # 运行 127 条自动化测试（含安全测试、模拟邮件服务器与半年业务模拟）
node scripts/seed-demo.js                      # 生成约半年的模拟业务数据到 data/erp.db（先停止服务器；原库自动完整备份）
node scripts/audit-data.js data/erp.db         # 数据一致性审计（26 项账货单状态交叉检查）
```

数据保存在 `data/erp.db`（单文件，复制即备份）。同一局域网的手机可通过 `http://电脑IP:8080` 访问。

## 亿星兼容与数据迁移（V7）

- 客户、厂家、样品档案补充亿星常用字段（英文全称、跟单员、价格条款、付款方式、佣金、采购类型、厂家状态、合作厂家、包装率内/中/外、CBM、净毛重、系列、海关编码、停用等）。
- 【系统设置 → 数据迁移（亿星导入）】：导入亿星导出的 Excel/CSV，按亿星列名自动识别，先校验再导入，结果按亿星方式分类，可整批回滚。
- 亿星操作习惯（V8）：所有档案和单据列表左侧有导航树（可自定义 3 级分组并显示数量）和快速查找区，表头可排序、可像 Excel 一样勾选过滤，可设置显示哪些列，设置按账号保存；客户详情增加联系人、唛头、货代、银行账号页签；【系统设置 → 业务交接】离职/调岗一键转交客户和单据。
- 报价与订单（V9）：报价按行利润率、单价锁定、换汇成本、物流报关费按体积(CBM)分摊，编辑时利润率与单价实时互算；报价复制、另存为送样单；订单概要/合同条款/唛头（新单自动带出客户付款方式、目的港、默认唛头）、加减项（计入合同总额与应收）、效益测算（预估 vs 实际）、翻单；报价/订单明细支持“历史记录导入”。
- 出货与财务（V10）：【出货中心（发票）】一张商业发票合并同一客户多张订单、分多个柜，自动算箱数/体积/毛净重，报关明细按海关编码汇总，整票报关/出运，打印商业发票、装箱单；【应收账款台账】按订金、出货、加减项、其他应收生成，按到期日冲抵并显示账龄；【水单认领】财务登记到账、业务员认领到本人订单自动生成收款，小额差异可销账；【应付账款台账】付款到期日=交货期+供应商账期。
- 样品明细（V11）：样品详情增加配件明细、包材明细、工序明细、包装方案页签，汇总每只成本并可回写样品成本；默认包装方案同步样品包装资料；订单明细可选包装方案（出货按方案算箱数体积）；订单“材料需求”按用量自动分解并按供应商一键生成采购单。
- 库存与验货（V12）：多仓库，所有库存变化记入库存流水（期初、采购入库、领料、其他出入库、调拨、盘盈盘亏、档案调整），按仓库查询库存、出入库明细；库存盘点（财务确认后自动盘盈盘亏）；验货单（AQL、致命/严重/轻微缺陷、按货号抽检），结果自动同步出货单验货状态。
- 成品库存与询价（V13）：订单详情“成品库存（按订单）”做产品入库、按出货单出库、退货，出货中心可按发票出库，系统参数可设“出运前必须先出库”；数据迁移增加样品配件/包材明细、工序明细、包装方案导入；【报价管理 → 配件/工序询价】从样品明细勾选向供应商询价，多家比价后采用，单价与供应商写回样品明细并记入历史价格。
- 调研结论、功能差距与后续分批计划见 [docs/05-亿星兼容与数据迁移方案.md](docs/05-亿星兼容与数据迁移方案.md)。

## 安全机制（V4）

- **密码策略**：至少 10 位，须含大写、小写、数字、特殊符号，不能含账号名、常见弱密码、3 个以上相同或连续字符；新建、重置、修改密码均强制校验。
- **临时密码与强制改密**：新建账号或重置密码时由系统生成一次性随机密码（只显示一次）；首次登录、或用旧的弱密码登录时，必须先改密码才能使用任何业务功能。改密后其它设备上的登录自动失效。
- **防暴力破解**：同一账号连续输错 5 次锁定 15 分钟（可在系统参数调整），管理员可解锁；同一 IP 10 分钟内失败 20 次暂停登录；不同提示不泄露账号是否存在。
- **请求限流**：匿名请求按 IP、登录后按账号限流（同一办公室共用出口 IP 不会互相影响）。
- **浏览器安全**：内容安全策略（CSP，无任何内联脚本）、禁止被嵌入（防点击劫持）、禁止 MIME 嗅探、不发送来源信息；下载文件在沙箱中处理；退出登录清除屏幕内容。
- **服务端**：令牌只接受请求头不接受网址参数；错误信息不暴露内部细节（只给错误编号）；静态文件防路径穿越与隐藏文件访问；防慢速连接攻击；邮箱服务器地址防 SSRF（默认禁止内网地址与非邮件端口）；系统参数白名单校验；邮箱密码 AES-256-GCM 加密；全部 SQL 参数化。
- 部署到公网时建议放在 HTTPS 反向代理之后（系统会自动发送 HSTS），并妥善备份 `data/erp.db` 与 `data/secret.key`。

## 企业邮箱、汇率、图片（V2）

- **企业邮箱**：「业务邮件 → 邮箱账户」添加自己的邮箱，点「按邮箱自动识别」自动填写服务器参数，填写密码/授权码后「测试连接」。之后即可在系统内写信、回复、收信（默认每 10 分钟自动收取），邮件自动绑定客户/报价/订单/样品；询价单可一键邮件发给厂家（自动附 Excel）。密码加密存于数据库，密钥在 `data/secret.key`（请与数据库一起备份）。
- **汇率**：币种汇率页「⟳ 自动更新汇率」，默认每 24 小时自动更新，波动异常自动拦截。
- **样品图片**：样品详情页「＋ 上传图片」，自动压缩。
- **邮件模拟测试**：`node tests/mock-mail-server.js` 启动本机模拟邮件服务器（ai001/ai002/ai003@316191099.xyz，密码见该文件），用于不连接真实邮箱的演练。
- 不需要定时任务时可用 `node server/index.js --no-scheduler` 启动。

## 目录结构

```
server/            后端（零依赖 Node.js）
  index.js         启动入口
  app.js           路由装配与错误处理
  db.js            建表与演示数据
  entities.js      档案类实体元数据（通用增删改查）
  xlsx.js          Excel 生成器
  xlsx-read.js     Excel/CSV 读取器（数据迁移导入）
  migrate.js       数据迁移引擎（亿星列名识别、校验、批次回滚）
  routes/          base(权限/档案/审批) sales(报价/询价/送样) orders(订单/风控/出货)
                   finance(应收/采购/库存/生产) reports(报表/设计师) migrate(数据迁移) handover(业务交接) shipping(出货中心) ledger(应收应付台账/水单) stock(仓库/盘点/验货)
public/            前端单页应用（原生 JS，手机自适应；listkit.js 为导航树/查找/排序过滤通用列表）
pages/            浏览器演示版运行时（Node 内置模块替代、请求拦截、IndexedDB 存储）与 sql.js
scripts/          build-pages.js 演示版构建；seed-demo.js 业务模拟器；audit-data.js 一致性审计；sample-art.js 样品图生成
tests/             自动化测试
docs/              原型、功能设计、测试用例、测试报告、亿星兼容与数据迁移方案
```
